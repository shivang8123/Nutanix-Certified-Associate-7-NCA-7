## 📚 What You Need to Study

The exam is organised into **4 sections** (Nutanix does not publish percentage weights).

### Section 1 – Recognize Nutanix Solutions and Tools
- Nutanix Cloud Infrastructure (NCI): **AOS** (distributed storage), **AHV** (hypervisor), **Prism**
- Nutanix solutions and use cases: disaster recovery, Flow (network security / virtual networking), Nutanix Cloud Clusters (NC2), Unified Storage (Files, Objects, Volumes), Nutanix Database Service, Nutanix Kubernetes Platform, Nutanix Cloud Manager
- Non-Nutanix technologies in the NCI space (how third-party hypervisors/platforms compare and where they fit)
- Nutanix tools: **Move** (migration), **LCM**, **Insights**, **X-Ray**, **Sizer**, and similar

### Section 2 – Describe Nutanix Platform Administration
- **VM tasks:** create, power on/off, clone, snapshot, update, migrate, delete; guest tools (NGT)
- **Virtual networking:** VLANs, subnets, virtual switches, bridges, uplinks, IP address management
- **Storage operations:** storage containers, storage pools, data efficiency (compression, dedup, erasure coding), replication factor, volume groups
- **Licensing:** license types, applying and reclaiming licenses, where to manage them in Prism

### Section 3 – Describe Cluster Configuration and Maintenance
- Valid cluster options and cluster configuration basics (nodes, Prism Element vs. Prism Central)
- **Hardware maintenance:** node/disk add, remove, replace, maintenance mode
- **Software maintenance:** **LCM** inventory and upgrades for AOS, AHV, firmware

### Section 4 – Platform Health and Monitoring
- Run and **interpret the Cluster Health checks (NCC)**
- Review and interpret **alerts and events**
- Leverage support functions (Nutanix Support Portal, log collection, case handling)
- Review and interpret **workload and cluster performance** charts in Prism

## 💡 Exam Tips

- Get hands-on with **Prism Element and Prism Central**. Many questions test where to find something and what it means.
- Know the **purpose of each product** and which one fits a given use case.
- Be able to read **health checks, alerts and performance graphs** and explain what they indicate.
- Learn the **LCM workflow** (inventory → updates) for software and firmware.
